# TRAMA ZERO — Fashion Commerce Demo

**TRAMA ZERO** is a fictional unisex modular clothing label created as an original portfolio concept for **Punto Due Studio**.

The project explores the idea of clothing as a system of layers: garments, information and digital interaction are treated as parts that can be assembled, detached and reconfigured.

> Fictional portfolio demo. TRAMA ZERO is not presented as a real client or commercial collaboration.

## Creative direction

- Bone / ink / oxide material palette
- Editorial fashion-commerce layout rather than a generic storefront
- Custom interactive **Weave Field** built in Three.js
- Higgsfield-generated campaign imagery
- Product storytelling built around modular construction
- Intentional mobile ecommerce experience

## Pages

- `index.html` — campaign, collection and interactive brand experience
- `product.html` — fictional product-detail commerce experience
- `404.html` — branded not-found page

## Stack

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- Three.js for the interactive Weave Field
- Static Netlify deployment

## Netlify

No build step is required.

- **Branch:** `main`
- **Base directory:** repository root
- **Build command:** none
- **Publish directory:** `.`
- **Functions directory:** none
- **Environment variables:** none

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
